# NexoraTrade

NexoraTrade is a dark-first, educational paper-trading application built with Next.js 15, React 19, TypeScript, Tailwind CSS v4, Neon Postgres/Auth, Drizzle ORM, Zod, Recharts, Vitest, and an in-house SVG candlestick chart.

**This application is a demo trading simulator. It does not connect to a brokerage and does not place real-money trades.**

## Current product capabilities

- Generated simulated OHLCV candles for fictional Nexora instruments.
- In-house responsive SVG candlesticks, volume, SMA 20, crosshair, zoom/pan, fit-to-data, timeframe switching, and quote metadata.
- Horizontal application navigation and global symbol search in the header, with a responsive market watchlist alongside the chart.
- Supported instruments are the 17 fictional Nexora symbols listed in `src/lib/demo-instruments.ts`.
- Batch simulated quotes and gainers/losers filters.
- Authenticated demo account, server-validated simulated market orders, cash and position checks, idempotency, fills, ledger entries, and persisted positions.
- Interactive beginner academy with server-validated quizzes, persisted completions, and one-time XP awards.
- Strategy Lab with deterministic SMA crossover backtests, explicit fee/slippage assumptions, position caps, and next-bar execution. Backtests do not place orders.
- Privacy-first monthly demo leaderboard, based on recorded portfolio snapshots and explicit user opt-in.
- New demo accounts start with $3,000 virtual cash. Successful fills add a buy/sell marker and a brief, local-only simulated price impact on the Trade chart.
- Account/portfolio views, stored equity snapshots, order history, and per-user persistent watchlists.

## Market simulation

All displayed market prices and candles are generated by NexoraTrade for practice. They are fictional, are not sourced from exchanges, and are not suitable for investment decisions. The demo quote oscillation is illustrative and does not represent actual market conditions.

## Environment variables

Set these in the environment where the app runs:

- `DATABASE_URL` (preferred) or `DATABASE_URL_UNPOOLED`: Neon Postgres connection string for that environment. The app falls back to `DATABASE_URL_UNPOOLED` when the pooled variable is not configured.
- `NEON_AUTH_BASE_URL`: Neon Auth URL for the matching Neon branch.
- `NEON_AUTH_COOKIE_SECRET`: high-entropy secret of at least 32 characters. Generate locally; never commit or share it.
- `NEXT_PUBLIC_NEON_AUTH_URL`: public Neon Auth URL used by the existing app setup.
- `NEXT_PUBLIC_APP_URL`: app origin.

Do not commit secret values. Keep each environment's database URL and Auth URL matched to the same Neon branch.

## Database migrations

The schema migrations are `drizzle/0001_core_trading.sql`, `drizzle/0002_demo_market_symbols.sql`, `drizzle/0003_demo_only_market.sql`, `drizzle/0004_demo_starting_balance.sql`, `drizzle/0005_progression_academy.sql`, `drizzle/0006_instrument_metadata.sql`, and `drizzle/0007_opt_in_leaderboards.sql`. Migration 0003 disables legacy real-market assets and removes them from saved watchlists while preserving historical order records. Migration 0004 sets the new/reset virtual balance to $3,000 and preserves accounts with trading activity.

All seven migrations (`0001`–`0007`) have now been applied to and verified on both the dedicated Neon development branch `nexoratrade-development` (`br-wandering-brook-b4hkz1hg`) and the production branch (`br-icy-bonus-b4nmq99p`). Production now has the 15 public application tables plus the existing 9 `neon_auth` tables. Verification confirmed 29 asset records, 17 active fictional Nexora instruments, sector metadata on all 17 active instruments, four seeded academy lessons, the XP ledger and opt-in leaderboard schema, and a default virtual starting balance of $3,000. The order and reset functions were verified to use the updated demo-market behavior. The production application tables were empty before migration; no demo trading accounts or user trading history were migrated from development.

Keep production and development environment variables matched to their corresponding Neon branches. Any future production schema change should be reviewed and explicitly approved before execution. Do not point a development build at the production branch.

## Local setup

1. Install Node.js 20 or later.
2. Copy `.env.example` to `.env.local` and fill in development-branch settings.
3. Install dependencies with `npm install`.
4. Run `npm run dev`.
5. Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build` before release.

## Routes

- `/` — overview, simulated market watch, and account summary.
- `/markets` — candlestick chart and instrument selection.
- `/trade` — simulated market-order ticket.
- `/portfolio` — current positions and recorded equity history.
- `/orders` — persisted demo order history.
- `/watchlist` — saved user watchlist.
- `/academy` — four interactive beginner lessons with server-validated quizzes, saved completions, and one-time XP rewards.
- `/bots` — deterministic strategy backtesting with simulated fees, slippage, and next-bar fills; no live bot execution.
- `/leaderboard` — opt-in public monthly rankings from recorded portfolio snapshots.

## Known limitations / release checklist

- Prices and candles are simulations, not live market data.
- Market orders are simulated. The Strategy Lab charges assumed costs only in its backtest; trading-engine fees, pending limit orders, cancellation, short selling, persistent bot execution, and brokerage integration are not enabled.
- Equity snapshots are recorded when the authenticated account endpoint is viewed, at most once per 15 minutes. They are not a scheduled continuous portfolio feed.
- Production schema is now installed; persistent features still depend on correct production database and Neon Auth environment variables.
- Verify the Vercel deployment and all environment settings before considering the release operational.
